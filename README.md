
## 🚀 YOLOv11 Object Detection from Images

## Live App Link : https://yoloimagedetectionproject-xdfnhbiy83hdw4ngurnplk.streamlit.app/

This project implements a **custom-trained YOLOv11 model** for **object detection in images**. The model efficiently detects and classifies objects with high accuracy and fast inference, making it suitable for real-world computer vision applications.

### ✨ Highlights

* Image-based object detection
* YOLOv11 deep learning architecture
* High accuracy with fast performance
* Bounding boxes with class labels and confidence scores

### 🛠️ Technologies Used

Python, YOLOv11, PyTorch, OpenCV

### 📌 Applications

Surveillance, smart systems, industrial inspection, and AI-based image analysis.

### 🚧 Future Scope

Real-time detection, video processing, and web app deployment.
